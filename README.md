## About

This repository contains scripts for creating nucleotide and amino acid alignments using 118 pea genomes and a reference pectin acetylesterase gene. The workflow processes whole genome sequences from three different pea species and generates both nucleotide and protein sequence alignments through a series of automated steps including BLASTn searches, sequence extraction, translation, and alignment.

**Key Features:**
- Automated processing of 118 pea whole genomes
- Reference-guided alignment using pectin acetylesterase gene sequences
- Generation of both nucleotide and amino acid sequence alignments
- Support for multiple species (pea and chickpea)
- Modular workflow with distinct processing steps
